# 数据产品交互手册

一个零依赖、可直接打开的数据产品组件速查站。

包含：

- 10 个清晰分类、78 个常见数据产品交互模式
- 32 种图表交互，以及数据表格、筛选视图和看板布局专题
- 每个组件都有符合自身特点的循环动画和可操作 Demo
- 支持全站搜索、按任务查找、收藏、最近浏览、相似模式和常用组合
- 每个模式只保留使用时机、核心效果和可复制 AI 指令
- 真实省市区搜索与级联、多选、拖拽、筛选、排序、下钻和联动状态
- 白色顶栏一级分类 Tab、左侧二级组件目录和移动端响应式布局

直接双击 `index.html`，或在本目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。
